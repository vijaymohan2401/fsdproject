## 🎯 Dual Architecture: SpendWise Capstone vs Individual Experiments

1. **SpendWise Capstone Project (`/frontend` & `/backend`)**:
   - The master Personal Expense Tracker web application.
   - Clean, professional, student-focused financial management tool.
   - Features Light Blue default theme (with Orange & Pink accent switchers).
   - Contains NO awkward syllabus badges or unnecessary quiz pages in its user interface.

2. **Standalone Syllabus Suite (`/lab-experiments`)**:
   - Contains an isolated, directly executable program for each prescribed syllabus topic from 1a to 15b + all augmented programs.
   - Designed for easy demonstration to lab instructors and external examiners.
